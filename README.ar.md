# ميديا تولز

مشغّل وسائط محلّي للصور والفيديو والصوت. أفلِت الملفات، وشغّلها كقائمة تشغيل،
ويتذكّر التطبيق من أين توقّفت.

بدون خطوة بناء، بدون إطار عمل، بدون شبكة. جافاسكربت عادي، ونسخة مُضمَّنة من
مكتبة تشغيل واحدة، وخادم ملفات ساكن من ١٠٥ أسطر.

**[English](README.md) | العربية**

---

## التشغيل

```bash
npm install      # للاختبارات فقط
npm start        # http://localhost:8000
```

`npm start` يشغّل `serve.js`، وهو خادم ساكن بلا أي اعتمادية. فتح `index.html`
مباشرة من نظام الملفات **لا يعمل**: العناصر المخصّصة وتحميل الوحدات يحتاجان
مصدرًا حقيقيًا (origin).

إذا كان المنفذ 8000 مشغولًا، يختار الخادم منفذًا آخر ويطبعه.

## الاستخدام

**إضافة ملفات** — أفلتها على النافذة، أو على لوحة قائمة التشغيل. الإفلات على
النافذة يبدأ التشغيل فورًا؛ والإفلات على اللوحة يضيف إلى النهاية دون مقاطعة
ما يعمل بالفعل.

**التشغيل** — انقر على الصورة، أو اضغط <kbd>Space</kbd>. انقر نقرًا مزدوجًا
للملء الشاشة.

**إعادة الترتيب** — اسحب صفًّا من القائمة. تُعاد ترتيب القائمة أثناء السحب،
فالذي تراه أثناء السحب هو النتيجة. أفلت خارج القائمة للإلغاء.

**كل ما عداه** — اضغط <kbd>?</kbd> لقائمة الاختصارات والمفاتيح كاملة. وهي
موجودة أيضًا في `requirements.md`.

| <kbd>D</kbd> <kbd>C</kbd> <kbd>S</kbd> | الملاءمة: افتراضي / قص / تمديد |

للنافذة.

### الإعدادات

زر الترس في شريط التحكّم يفتح نافذة الإعدادات.

- **اللغة** — English أو العربية. تتعكس الواجهة بالكامل، بما فيها شريط التقدّم
  واللوحة والأرقام.
- **الشعار** — استخدم صورتك في نافذة البداية، أو أزله. الزر نفسه يعيد الشعار
  المرفق، فالإزالة ليست طريقًا بلا رجعة.
- **لون الهوية** — أي لون. ذهب الشعار نفسه، `#aa7827`، هو الافتراضي، والزر
  المجاور للمحدِّد يعيده.

الصور الكبيرة تُصغَّر قبل تخزينها. وإذا امتلأت مساحة التخزين في المتصفح، تقول
نافذة الإعدادات ذلك صراحةً بدل أن تفقد إعداداتك الأخرى بصمت.

## ما يُحفظ

مستوى الصوت، والكتم، ووضع الملاءمة، ومبدآي التكرار والتشغيل التلقائي، وهل
شريط التحكّم ولوحة التشغيل مفتوحان، وموضعك، واللغة، والشعار، ولون الهوية.

**قائمة التشغيل نفسها لا تُحفظ** في المتصفح: الملف المُفلَت في الصفحة ليس سوى
اسم، وتخزين القائمة ينتج صفوفًا لا يمكن تشغيلها. هذا هو سبب وجود هيكل سطح
المكتب لاحقًا — انظر أدناه.

## الاختبارات

```bash
npm test           # ٨٤ اختبار وحدة، داخل jsdom، بلا متصفح
npm run test:media # توليد ملفات الاختبار (يحتاج ffmpeg)
npm run test:e2e   # ٥ مجموعات اختبار في متصفح مخفي
npm run test:all
```

`npm test` يحمّل `index.html` الحقيقي والسكربتات الحقيقية، ولا يقلّد سوى مكتبة
التشغيل — وهو بالضبط الحدّ الذي وُجد `js/media.js` لأجله. هذا يبقي الاختبارات
سريعة وحتمية دون أن تنزلق بعيدًا عن الشيفرة المشحونة.

`npm run test:e2e` يحتاج ثنائي Electron (`/usr/lib/electron41/electron`، أو
اضبط `ELECTRON_BIN`). يشغّل خادم التطبيق بنفسه و**يوجّه صوت الاختبار إلى
مخرَج صامت**، فتعمل الاختبارات بلا أي صوت.

## بنية الملفات

```
index.html          الشيفرة المصدّرة وأيقونات SVG المضمّنة
app.js              كل حالة التطبيق: القائمة، اللوحة، الإفلات، المفاتيح، النوافذ
js/media.js         الملف الوحيد الذي يعرف بوجود مكتبة تشغيل
js/source.js        اختيار محوّل مصدر الملفات
js/source-web.js    محوّل المتصفح: روابط الكائنات، أنواع MIME، الحفظ

styles-vidstack.css تنسيق عناصر تحكّم المكتبة
serve.js            خادم الملفات الساكن
```

`requirements.md` هي الوثيقة المرجعية للمواصفات. بقية التوثيق في [`docs/`](docs/).

## ملاحظات التصميم

بعض القرارات التي لا تظهر بوضوح من الشيفرة، وقد شرحتها الشيفرة نفسها بتفصيل
أطول في مواضعها:

- **مكتبة التشغيل معزولة.** `js/media.js` هو الملف الوحيد الذي يعرف بوجود
  Vidstack، وهو مخرج الطوارئ: استبدال المكتبة يعني إعادة كتابة هذا الملف
  وحده، لا التطبيق كله.
- **لا حدود في أي مكان.** العنصر المحدَّد أو المركَّز عليه هو خلفية مسطّحة
  مع حافة داخلية ٢ بكسل. كل حدّ مرسوم كخطّ صلب يُقرأ كخطّ رمادي شارد، وهو
  تحديدًا ما يمنع موجز التصميم.
- **الل面板 بكامل الارتفاع، والشريط فوقها.** البديل — تقصير اللوحة لإفساح
  مكان — يضيّع عرض الشريط الكامل ويترك فراغًا يتغيّر كلما التفّ الشريط.
- **خريطة مفاتيح المكتبة تُمسح.** هي تربط `l` و`j` والأسهم و`m` و`f` و`c`
  افتراضيًا، وتقرأ أحداث المفاتيح نفسها التي يقرأها التطبيق، فكان كل حرف
  يعمل مرتين. التطبيق يملك كل اختصار ويوثّقه.
- **لون الهوية مجموعة من خصائص CSS.** تغيير اللون كتابة واحدة، ويتبعه ملفّا
  التنسيق معًا.

## لم يُنجَز بعد

البث (HLS/DASH)، والترجمة، والتحكم بالسرعة، وصورة داخل صورة، والتحرير، وقراءة
الوسوم، والنوافذ المتعددة، وأي مصدر شبكي. هيكل سطح المكتب مُخطَّط ولم يبدأ —
انظر `docs/system-design.ar.md` لما يُغيّره وما لا يُغيّره.
